### `02` / On the workbench

<a href="https://github.com/sudiptacmd/homedroid"><img src="assets/homedroid.svg" width="100%" alt="Homedroid: your old Android phone, now a home server. SSH, web hosting, media, photos, and home automation. No root required."></a>

**[Homedroid](https://github.com/sudiptacmd/homedroid)** brings SSH, web hosting, Jellyfin, Immich, qBittorrent, and Home Assistant to an Android phone, with a web dashboard to manage it all.

[Get the latest release ↗](https://github.com/sudiptacmd/homedroid/releases/latest) &nbsp; · &nbsp; [See how it works ↗](https://github.com/sudiptacmd/homedroid#readme)
